# Decision records

Short ADRs. Each one gives the decision, the reason and the open points. Status is `Accepted` (decided by the maintainer or directly implied by the design) or `Proposed` (a reasonable default that still needs the maintainer's confirmation). To change a decision, add a new ADR that supersedes the old one.
